# 托管 Caddy 上游

[English guide](CADDY_MANAGED.en.md)

> 本功能自 **0.5.7** 起随包发布。

## 适用场景

你有自己的域名，想让手机从公网访问 DSH，但不想手动安装反向代理、申请证书或编写配置。在电脑端 **移动访问 → 远程 → 自建连接 → 自有反向代理 → 托管 Caddy** 中启用本功能，插件会：

1. 下载固定版本的 Caddy（含腾讯云 DNS 插件，用于 DNS-01 证书验证）到插件私有目录；
2. 生成并管理 Caddyfile；
3. 以子进程方式运行 Caddy，随远程提供方切换自动启停。

```text
手机 → https://phone.example.com:8443（插件托管的 Caddy 终结 TLS，DNS-01 自动签发续期）
     → http://127.0.0.1:3444（本插件的私有 HTTP 后端）
     → 当前 DSH WebServer
```

## 与"自有反向代理"的关系

同一个私有 HTTP 后端（3444），两种公网 TLS 方式：

- **我已自行配置反向代理**：你管理 Lucky/Nginx/Caddy 与证书，插件只提供后端（原有方式，见 [自有 HTTPS 反向代理](SELF_HOSTED_ORIGIN.md)）。
- **托管 Caddy**：插件管理一切，你只需一个域名和 DNS API 凭据。

两者共享同一后端与配对设备，切换模式不影响已配对的设备。

## 填写四项设置

| 字段 | 说明 |
| --- | --- |
| 公网域名 | 完整 HTTPS 地址，如 `https://phone.example.com:8443`。端口必须与路由器转发一致。 |
| DNS 提供商 | 首版支持腾讯云 DNSPod（DNS-01，无需公网 80/443）。 |
| 腾讯云 SecretId / SecretKey | 用于 DNS-01 验证的 API 凭据；仅保存在插件私有目录，不写入 Caddyfile 或日志。 |
| 公网 HTTPS 端口 | Caddy 监听端口，默认 8443；不能为 3443（LAN 网关）、3444（后端自身）或 3080（DSH）。 |

路由器需将公网 HTTPS 端口转发到本机的该端口。

## 组件来源

Caddy 为官方定制构建（caddy 核心 + 腾讯云 DNS 插件），固定版本并经 SHA256 校验后安装到插件私有目录。**不添加系统服务、PATH 条目或开机启动项**；停止远程访问后 Caddy 随之退出。证书存储在插件私有目录内。

## 首次启动与证书

Caddy 首次启动会通过 DNS-01 完成证书签发，通常需要几十秒。面板显示"后端已监听"即本地链路就绪；公网 HTTPS 在证书签发完成后可用。证书后续由 Caddy 自动续期。

## 迁移自手动安装

如果你之前手动安装过 Caddy（例如注册为 Windows 服务）：

1. 停止并删除旧的服务/进程（`sc stop caddy` 与 `sc delete caddy`）；
2. 在面板中安装托管组件、填写域名与凭据；
3. 首次会重新签发证书（旧证书目录不迁移，属于一次性成本）；
4. 验证手机连接正常后，删除旧 Caddy 目录。

## 停止与清理

| 操作 | 结果 |
| --- | --- |
| 切换到其他提供方 | 停止 Caddy 与后端，保留配置与配对设备。 |
| 移除托管 Caddy 与设置（需确认） | 停止并删除组件、Caddyfile、凭据与证书数据；配对设备与 LAN 不受影响。 |

## 与 origin 后端的安全边界相同

托管 Caddy 只是替换了"谁来终结 TLS"，后端安全模型不变：设备配对、精确 Host/Origin 校验、CSRF、Secure Cookie、WebSocket 路径策略全部保留。公网只能通过 HTTPS 访问；HTTP 后端（3444）仅监听回环，不得暴露公网。
